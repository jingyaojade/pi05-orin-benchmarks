# π0.5 LIBERO：Orin baseline 与 FlashRT 对照

2026-10-16，Jetson AGX Orin 64GB / SM87，L4T R36.3、CUDA 12.2、NVIDIA PyTorch 2.3。FlashRT BF16 的生产完整图模型墙钟为 **230.918 ms/action chunk**，相对最初 baseline 加速 **3.807×**，相对相邻重测 baseline 加速 **4.207×**。

## 生产模型与完整策略

每阶段排除 10 次预热，统计 30 次测量。输入就绪于 GPU、结束前同步 GPU 的模型墙钟包含主机发射开销，排除 CPU 预处理、输入传输、输出传回和动作解码。完整策略还包含这些前后处理，均排除网络。

| 实现 / 测量 | 模型均值 ms | 模型中位 ms | 模型 p95 ms | 完整策略均值 ms |
| --- | ---: | ---: | ---: | ---: |
| 最初 OpenPI baseline | 879.124 | 880.175 | 882.884 | 886.895 |
| 相邻重测 OpenPI baseline | 971.478 | 971.691 | 1006.392 | 968.795 |
| FlashRT BF16 | 230.918 | 230.659 | 232.443 | 237.707 |
| FlashRT INT8 实验 | 170.847 | 170.856 | 171.396 | 见原始报告；动作偏差较大 |

最初 baseline 记录完成于 12:00，BF16 于 13:17，相邻 baseline 于 13:21，INT8 于 14:29（北京时间；精确 UTC 时间见各 provenance）。最初 baseline 完成后主机新增遥操作后台任务，因此另外保留相邻重测。两轮 baseline 的差异说明主机负载、动态频率和顺序测量会影响绝对耗时；这些耗时比是当前部署的实测比较，不是锁频、空闲主机下的芯片极限。

完整策略和模型分别采样，不能通过两项均值相减精确推导传输开销；相邻 baseline 两个阶段之间也存在漂移。

## 各主要部分

| 区间 | 最初 baseline ms | 相邻 baseline ms | FlashRT BF16 诊断图 ms |
| --- | ---: | ---: | ---: |
| 三路视觉编码合计 | 86.181 | 90.100 | 40.608 |
| VLM 前缀 KV 预填充 | 277.104 | 297.109 | 138.082 |
| 全部 10 次动作去噪 | 526.860 | 587.948 | 51.396 |

baseline 列来自插桩区间；模型主结论来自另行测量的未插桩模型。FlashRT 列来自分别捕获和发射的视觉、prefill、denoise 图，其输出与生产完整图一致。它们用于定位耗时，不能当作单个生产完整图的精确分解，也不能与 baseline 的父子区间重复相加。投影、归一化和 MLP 等算子在 FlashRT 中发生融合，本轮没有分别给出这些融合内部算子的独立计时。

baseline 的瓶颈主要是动作专家和前缀预填充；FlashRT BF16 中前缀预填充成为主要耗时。

## 输入、语义与数值

两套路径使用同一 checkpoint、norm stats、官方 tokenizer、固定图像、状态、指令和显式噪声；文件与数组散列、200 个 token IDs/mask 均已核对。输入保留三路 224×224 视觉计算（两路有效、第三路掩码），编码器保留 968 行、200 token 容量，输出 `10×7`，去噪 10 次。没有减少视觉层数、去噪步数，没有启用跨帧 KV 复用。

FlashRT 使用本仓库显式补丁，将有效文本 K/V 压紧到第三路掩码相机的空隙，以便 FA2 正确跳过无效键；视觉和 GEMM 的填充计算仍保留。补丁及上游 commit/hash 均随代码保存。FlashRT 还预计算时间调制，并使用 BF16 动作累积；OpenPI 保留部分 FP32 运算。因此跨后端不要求逐位相同。

| 相对 OpenPI 参考动作 | BF16 | INT8 实验 |
| --- | ---: | ---: |
| 余弦相似度 | 0.999832562 | 0.580659961 |
| RMSE | 0.007629676 | 0.415862718 |
| 最大绝对误差 | 0.032161510 | 2.299639547 |
| 平均绝对误差 | 0.004565323 | 0.185193528 |

两种 FlashRT 路径各自的 90 次测量输出均与各自首个输出逐位一致，生产图恢复检查通过。**INT8 在这组输入上的跨后端差异过大，本次不选作可用加速结论。** 运行时没有预设跨后端误差阈值；`BENCHMARK_COMPLETE` 表示执行和内部一致性检查完成，不代表通过机器人任务精度评估。

BF16 在这组固定合成输入上数值接近 baseline。单个合成观测不足以证明真实机器人任务成功率，实机使用仍需任务数据验证。
